# Security review — Phase 3

## Findings and disposition

| Finding                                                    | Severity      | Disposition                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Existing cleanup suites explicitly targeted production ref | High          | Fixed on dev: require APP_ENV=staging, explicit independent ref, and independent Sheet IDs before creating clients/fixtures. Never run these tests with production secrets.                                                                                                                          |
| Preview could inherit a production target                  | High          | Fixed on dev: proxy and server clients fail closed unless Preview URL matches explicit non-production staging ref. Missing configuration returns 503 before authentication/data access.                                                                                                              |
| Leaked password protection disabled                        | Medium        | Live Security Advisor WARN. Organization plan verified Free. Supabase documents this protection as Pro+. No billing changes. Owner should configure Auth minimum length >=12 and strong character requirements; app password form already requires 12, but UI validation cannot replace Auth policy. |
| Missing baseline security response headers                 | Low           | Added nosniff, DENY framing, no-referrer and restrictive camera/microphone/location policy. CSP is deferred until a nonce-based policy can be tested with Next runtime; no unsafe pretend CSP.                                                                                                       |
| Private quota table has no RLS policy                      | Informational | Intentional deny-all to clients, guarded functions only. Do not add permissive policies to silence advisor.                                                                                                                                                                                          |

Trusted roles remain in profiles, never user-editable metadata. Active profile is checked per request and by RLS. Role management preserves serialized last-Admin/self-change protection. Disabled session navigation clears current-session cookies and redirects to login; JWT validity alone grants no business access. Existing permission/reliability tests are retained, not relabeled as new staging results.

Review found parameterized PostgREST/RPC calls, allowlisted sorts and validated integer/date inputs; no dynamically concatenated SQL from input. React text escaping is retained; no user-supplied HTML execution. CSV uses formula escaping; Sheets export uses RAW, source parser rejects formula-like invalid business values. Secrets remain server-only; invitation diagnostics log stage/status, not credentials or recipient data. Audit rows necessarily contain business metadata: restrict access and encrypted backups accordingly.

Remaining: Auth policy configuration audit, perimeter login/IP abuse controls, current staging role/disable/RLS/invalid-import tests, and authenticated security-header QA are BLOCKED pending staging. Never weaken production roles, reset data, or trigger real provider outages to obtain a PASS.

References: [password protection](https://supabase.com/docs/guides/auth/password-security), [advisor](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy).
